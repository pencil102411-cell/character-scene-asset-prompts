# 写实转化提示词模板

> 配合 `references/概念图写实化.md` 使用。严格按两段结构输出，不省略参考图现状分析。

---

## 使用说明

- 本模板适用于：客户提供概念图/CG图/游戏原画/AI初稿，要求写实化、去油、重新光影
- 必须先看到用户实际上传的参考图。未上传图片，或当前环境无法查看图片时，不可套用本模板凭空输出——请用户上传或用文字描述画面
- 场景类和人物类均使用同一结构，区别在于诊断维度和转化词库来源不同（分别见 `references/概念图写实化.md` §3、§4）

---

## 输出结构

### 一、参考图现状分析

（3-5行，对应 `references/概念图写实化.md` §1 诊断清单，需包含：CG 感来源、光源现状、材质现状、色彩基调是否需整体调整、构图锁定项）

```
示例（场景类）：
原图为冷调暴风夜海景，云层浓重压迫，海浪反光呈规则塑料高光，
建筑材质过于鲜艳干净，远景轮廓生硬缺乏大气透视。
整体冷调氛围与最终呈现需求不符，需连带光源整体重做。
构图锁定项：建筑布局、地标位置、桥梁与殿宇群分布关系不变。
```

```
示例（人物类）：
原图皮肤呈蜡像感、过于光滑均匀，五官对称精修痕迹明显，
眼神呆滞直视镜头，发丝无碎发层次，服装材质发亮似塑料膜，
整体平光无明暗层次。棚拍灰背景光源逻辑本身合理，无需重做。
构图锁定项：四栏排版、人物五官骨相、服装款式、姿态不变。
```

### 二、转化提示词

（编辑式写法，保留项 + 改变项，明确到材质/光源/色调三个层面，中文为主，仅保留必要英文技术控制词）

```
保持 [构图/建筑布局/人物五官骨相/服装款式/姿态] 不变；

将画面光源由 [原光源描述] 调整为 [目标光源描述]
（若光源逻辑无需重做，改为：在原有 [光源逻辑] 基础上增加明暗层次）；

材质由 [CG渲染表现] 转化为 [写实材质描述]，
[补充具体材质/去油/环境侵蚀词，见 references/概念图写实化.md §3.2 / §4.1-4.3]；

[如为人物]：面部保留骨相个性化差异，加视线偏移与微表情，
皮肤加毛孔细纹与自然肤色变化，发丝加自然毛流与碎发；
[如为四栏资产卡]：特写栏保留侧逆光层次，全身栏改柔和均匀光，
全身照面部哑光粉感，无成片反光；

[如为场景]：中远景之间补充空气透视层（薄雾/体积光/湿气），
消除贴图背景感；

整体去除 CG 厚涂感/塑料感，呈现真实摄影/真人拍摄质感。

画幅：[默认16:9，或按参考图比例]
质量后缀：[电影级画质，真实摄影质感]
避坑词：[不要塑料感，不要蜡像感，不要过度磨皮，不要AI感，
不要均匀平光，不要规则反光，不要面部油光]
```

## 保留项 / 改变项对照速查

| 类别 | 保留项（不可变） | 改变项（可转化） |
|------|----------------|----------------|
| 场景 | 建筑布局、地标位置、空间关系、整体构图 | 光源氛围、材质质感、色彩基调、大气透视 |
| 人物 | 五官骨相轮廓、服装款式结构、姿态、构图排版 | 皮肤质感、材质反光方式、光影层次、发丝细节 |

---

## 输出后

如果用户在做成体系的项目，询问是否把本次转化决策（保留项/改变项的具体判断、光源是否重做）记入项目看板（`templates/项目看板模板.md`，存放在用户当前项目目录）。
