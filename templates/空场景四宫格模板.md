# 空场景四宫格模板

> 配合 `references/场景构建.md` 使用的空场景氛围图模板。
> 分两步执行：先输出单张总图，用户确认后再输出四宫格分解。

---

## 工作流程

```
Step 1：输出单张总图提示词（含场景整体描述、风格锚点、光照、材质）
              ↓ 用户确认
Step 2：从同一场景中心点向四个方位取景，输出 2×2 四宫格提示词
```

---

## Step 1：单张总图模板

### 格式

```text
【场景名称】

风格锚点：【选择五大风格之一，或自定义】

[风格与时代锚点详细描述]
环境与建筑：[空间类型 + 建筑材质 + 环境侵蚀感]
材质叙事：[2-3处核心材质细节，强调时间、温度、湿度痕迹]
光影与氛围：[主光源方向 + 冷暖色调对比 + 体积光/丁达尔效应 + 光学瑕疵]
镜头机位：[焦段 + 拍摄角度 + 静帧镜头物理感（前景虚化、焦外层次等）]
画质控制：[前中后景分层 / 空气透视 / 远景可读 / 去油材质]

空场景，不出现人物。

Negative Prompt：
[针对场景类型的负面词]
```

> 风格注入词只用"风格词"，不要带汉服、人物服装类题材词——空场景里写了这类词，模型容易凭空加人。

---

## Step 2：四宫格分解模板

### 方位映射

```
┌──────────────────┬──────────────────┐
│                  │                  │
│  方位A / 左上     │  方位B / 右上     │
│  正向视野         │  左转90°方向     │
│  （主入口方向）    │  （左侧视野）      │
│                  │                  │
├──────────────────┼──────────────────┤
│                  │                  │
│  方位C / 左下     │  方位D / 右下     │
│  后转180°方向     │  右转90°方向     │
│  （回望来路视野）  │  （右侧视野）      │
│                  │                  │
└──────────────────┴──────────────────┘
          2×2 四宫格，单格 16:9
```

### 空间逻辑规则

- 锁定的是同一个**场景坐标系**，不是锁定同一个单体物件
- 允许不同方位出现不同地标（巨树只在东侧画面占主导，山门只在北侧画面出现）
- 禁止强行让同一棵树/同一座建筑/同一主体在四格里都占据核心位置
- 四格必须在地形、道路、溪流、门洞、柱阵、光源方向、雾层高度、材质年代上能互相拼合
- 必须像同一个摄影机在同一个空间中心点原地转身拍摄
- 自然场景：优先锁定山体走向、溪流走向、树木方位、雾层高度、日出/日落方向
- 建筑场景：优先锁定入口、主轴、左右廊道、背后空间、柱网、门槛、灯源、地砖纹理

### 格式

```text
【场景名称】— 四方位勘景

风格锚点：【同总图】

空间坐标系：[简述场景中心点位置 + 四个方位的主要地标]

─────────────────────────────────────

方位A（左上）— 正向视野 / 主入口方向
[景别：全景/大全景] + [方位特有的地标和材质] + [此方位的光影特征] + [空气透视状态]

方位B（右上）— 左转90°方向 / 左侧视野
[景别：全景/大全景] + [方位特有的地标和材质] + [此方位的光影特征] + [空气透视状态]

方位C（左下）— 后转180°方向 / 回望视野
[景别：全景/大全景] + [方位特有的地标和材质] + [此方位的光影特征] + [空气透视状态]

方位D（右下）— 右转90°方向 / 右侧视野
[景别：全景/大全景] + [方位特有的地标和材质] + [此方位的光影特征] + [空气透视状态]

─────────────────────────────────────

共用的光学质感：[统一的光学瑕疵 + 画质控制词]

空场景，四格均不出现人物。

Negative Prompt：
[同总图的负面词 + 禁止人物的强化约束]
```

## 输出示例

### Step 1 示例

```text
【蓝调晨雾山谷 · 废弃山门】

风格锚点：古典/仙侠/东方

横屏电影级大全景，蓝调时刻，2.39:1宽银幕。
前景为被夜露打湿的残破石阶，苔藓斑驳，石缝长出野草。
中景为半坍塌的青石山门，门楣浮雕已风化模糊，石兽只剩轮廓。
远景是隐入晨雾的层叠山峦，最高处有孤塔剪影。
空气中有厚重山雾和潮气，丁达尔光从雾缝中斜射，形成稀薄光柱。
石材呈现哑光漫反射，表面有苔藓附着、边缘风化剥落、棱角磨圆。
anamorphic widescreen，轻微前景虚化，边缘轻微暗角，极轻微色差。

空场景，不出现人物。

Negative Prompt：
人物，人物剪影，人影，飞鸟，动物，现代元素，塑料感，油亮石材，过饱和，CG感，3D低模，均匀锐化，可读文字，UI，水印。
```

### Step 2 示例（用户确认后）

```text
【蓝调晨雾山谷 · 废弃山门】— 四方位勘景

风格锚点：古典/仙侠/东方

空间坐标系：中心点为山门前三级石阶处。正向（方位A）正对山门入口；左转90°（方位B）面向西侧残墙与山谷；后转180°（方位C）回望来路石阶与松林；右转90°（方位D）面向东侧断崖与溪涧。

─────────────────────────────────────

方位A（左上）— 正向视野：正对废弃山门入口
大全景，低仰角。山门正面占据画面主体，门洞内黑暗深邃，可见内院倒塌的廊柱剪影。门楣风化浮雕借侧逆光显出微弱凹凸纹理。门前石阶青苔在蓝调光线中呈暗绿。前景左侧有一半截石灯笼，右侧松枝垂落，形成天然框景。山雾在山门两侧缓慢翻涌。

方位B（右上）— 左转90°方向：西侧残墙与山谷
全景，平视。山门左侧残墙向远方延伸，墙体多处坍塌，墙根堆满碎瓦。墙外是倾斜向下的山谷，谷中雾气更重，可见下层树冠如云海。墙体石材布满霉斑地衣，墙头荒草在晨风中微斜。远处天际线开始泛暖光。

方位C（左下）— 后转180°方向：回望来路
大全景，略高角度。从山门向内看，前方是荒废庭院，地面石板被野草顶裂，两侧回廊屋顶已塌，露出焦黑梁架。正前方远处可见来时路的石阶消失在雾中。左侧有一口被藤蔓覆盖的八角井，右侧倒着一根朱红剥落的木柱。晨雾在庭院地面低处沉积，形成薄薄雾层。

方位D（右下）— 右转90°方向：东侧断崖与溪涧
全景，略俯。山门右侧紧邻断崖，崖壁垂直向下约十余米，底部有溪涧，水流在晨光中泛冷白色反光。对岸为密林，树冠层叠。雾在溪面以上两米处形成平流层，将崖壁与水面分离。崖边有一株斜生的古松，根系裸露，抓附在岩石裂缝中。

─────────────────────────────────────

共用的光学质感：anamorphic widescreen，极轻微前景虚化，边缘暗角，蓝调冷色温，胶片微颗粒，空气灰尘噪点。所有材质为哑光漫反射，无油亮反光。

空场景，四格均不出现人物。

Negative Prompt：
人物，人物剪影，人影，飞鸟，动物，现代元素，光源方向不一致，四格材质不统一，塑料感，油亮石材，过饱和，CG感，3D低模，均匀锐化，可读文字，UI，水印。
```

## 使用说明

1. **第一步只输出单张总图**，等用户确认后再出四宫格
2. 四宫格的单格画幅固定为 16:9
3. 四格共用同一组光学瑕疵参数和画质控制词
4. 自然场景和建筑场景的方位优先级不同（见空间逻辑规则）
5. 空场景不出现任何人物、剪影、模糊人形
6. **输出语言**：中文为主，仅保留必要英文技术控制词（anamorphic、film grain 等），不输出独立英文段落
7. **负面框**：示例里的 Negative Prompt 是负面词清单。平台有独立负面框时直接粘贴；没有负面框的平台（如 GPT-image），改写成"不要人物，不要人物剪影……"接在正向提示词末尾
