## 使用说明

1. **先定性别**：选择模板A（女性）或模板B（男性）
2. **填参数**：把【】占位符全部替换成具体参数（参数库见 `references/资产标准化.md` §2、§3、§5、§6；男性面部见 `references/角色设计.md` §1.5），多选项只保留一个
3. **定风格**：设定卡固定用实拍档（`references/风格美学锚点库.md` 档位表），不加美容光、冷暖分离、bloom。网剧/短剧宣传取"古偶/古装电视剧定妆照"；严肃影视、电影感项目取"电影级古装定妆照"，女性妆容同步改为"古装电影自然淡妆"。其他风格锚点的注入词插在"整体呈现"之前，一张卡只用一个风格
4. **脸部一致性策略**（单张直出）：
   - 脸只在第一栏出现：正面、侧面全身去头，背面不露脸，全身照小脸换脸、出油、头部放大的问题从构图上避开
   - 面部参数写死写具体：脸型、骨相、眼型、鼻梁、唇形全部用明确参数，不留"清秀""好看"类模糊词，后续表情板和镜头直接复用
   - 第一栏脸太小、第二三栏露出下巴或人物被放大、第四栏回头露脸，直接重 roll 整卡，默认不要用参考图修（GPT-image 实测：参考图会继承原图噪点和色调，把画面弄脏；其他模型见 `references/资产标准化.md` §1.3）
5. **非古装题材**（现代、科幻等）：保留排版、去头、比例镜头、分栏光照、背景和负面词；替换妆容、服装、发型、首饰段落，详见 `references/资产标准化.md` §8.3
6. **输出前检查**：
   - [ ] 四栏顺序：大脸特写 / 正面全身（去头）/ 侧面全身（去头）/ 背面全身（带头），第一栏略宽
   - [ ] 第一栏脸部占栏宽七成左右，上沿裁在发际线上方
   - [ ] 第二、三栏写明头部从颈部中段抹去、颈部以上留空，且与第四栏同大小、肩线脚底线对齐
   - [ ] 包含八至九头身 + 腿长、腰线、颈长描述 + 三栏身材比例一致 + 50mm 腰部高度平视
   - [ ] 第四栏完全背对、不回头；发型、发饰与第一栏一致
   - [ ] 光线按栏区分：特写侧逆光且背景无光晕，全身柔光
   - [ ] 四栏统一浅冷灰背景，颗粒只写"轻微"，没有写"不要干净无层次"
   - [ ] 服装材质包含真实织物描写
