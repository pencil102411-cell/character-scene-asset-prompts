## 使用说明

1. **先定性别**：选择模板A（女性）或模板B（男性）
2. **填参数**：把【】占位符全部替换成具体参数（参数库见 `references/资产标准化.md` §2、§3、§5、§6），多选项只保留一个
3. **定风格**：网剧/短剧宣传取"古偶/古装电视剧定妆照"；严肃影视、电影感项目取"电影级古装定妆照"，女性妆容同步改为"古装电影自然淡妆"。其他风格锚点的注入词插在"整体呈现"之前，一张卡只用一个风格
4. **脸部一致性策略**（单张直出）：
   - 面部参数写死写具体：脸型、骨相、眼型、鼻梁、唇形全部用明确参数，不留"清秀""好看"类模糊词——描述越具体，全身照小脸的漂移空间越小
   - 脸部漂移时直接重 roll 整卡，不要用参考图修（实测：参考图会继承原图噪点和色调把画面弄脏，且锁不住全身照小脸的五官）
   - 接受天花板：全身照头部像素少，一致性只能逼近、无法百分百，以第一栏特写为准即可
5. **非古装题材**（现代、科幻等）：保留排版、比例镜头、脸部锚点、分栏光照和负面词；替换妆容、服装、发型、首饰段落，详见 `references/资产标准化.md` §8.3
6. **输出前检查**：
   - [ ] 排版是否为四栏：特写 / 正面全身 / 背面全身 / 侧面全身
   - [ ] 是否包含头身比（1:7-1:7.5）+ 50mm平视镜头 + 等身高对齐约束
   - [ ] 三张全身照与特写是否为同一张脸（含侧面轮廓吻合描述）
   - [ ] 光线是否按栏区分：特写侧逆光，全身柔光 + 面部哑光粉感
   - [ ] 背景是否为纯白或浅灰白干净背景，颗粒是否只写"轻微"，没有写"不要干净无层次"
   - [ ] 服装材质是否包含真实织物描写
   - [ ] 负面提示词是否包含头身比、排版、全身照油光约束（不要大头 / 不要微表情格 / 不要全身照面部油光）
