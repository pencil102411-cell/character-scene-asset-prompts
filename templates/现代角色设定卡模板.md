## 使用说明

1. **先定性别**：模板C（女性）或模板D（男性）
2. **填参数**：面部参数见 `references/角色设计.md` §1（男性 §1.5）和 `references/资产标准化.md` §2.3；妆容、发型、服装、首饰见 `references/资产标准化.md` §8.3 现代参数库
3. **选服装**：至少一件贴身或收腰单品，并写明腰头位置，全身栏才看得出头身比；只穿长大衣、宽松卫衣时，把外套写成"搭在手臂上"或删掉
4. **定风格**：设定卡固定用实拍档。"韩系女团官方定妆照"只用于偶像角色；都市、职场、校园用"都市剧定妆照"，电影感项目用"电影级现代剧定妆照"
5. **重 roll 条件**：第一栏脸太小、第二三栏露出下巴或人物被放大、第四栏回头露脸、身材偏矮，直接重 roll 整卡；参考图规则同模板 A/B
6. **输出前检查**：
   - [ ] 四栏顺序：大脸特写 / 正面全身（去头）/ 侧面全身（去头）/ 背面全身（带头），第一栏略宽
   - [ ] 去头栏与第四栏同大小，肩线、脚底线对齐
   - [ ] 八至九头身 + 腿长、腰线、颈长描述 + 50mm 腰部高度平视
   - [ ] 至少一件贴身单品，写明腰头位置；每件衣物有一处具体使用痕迹
   - [ ] 妆容雾面、底妆哑光，没有水光肌、光泽唇一类词
   - [ ] 四栏统一浅冷灰背景
   - [ ] 负面提示词 = §9 通用块 + 现代追加（男性再加男性追加）
