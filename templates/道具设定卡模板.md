# 道具设定卡模板

> 服化道里"道"的资产卡：武器、法器、信物、文书、日用器物、现代随身物件。提示词正文只在本文件维护。
> 痕迹词从 `references/材质叙事词典.md` 取，去油、克制反光从 `references/写实质感控制.md` §二 取。
> 使用时将方括号 `【】` 中的内容替换为实际参数；`【A/B】` 形式的多选项只保留一个。
> 版式为左侧大主图 + 右侧局部特写。不要套用人物设定卡的等宽四栏：测试中"主视 / 正视 / 侧视 / 特写"四栏的前三栏几乎画成同一张，剑竖放在窄栏里只占很小面积，只有特写栏有细节。

## 模板E：道具设定卡

```text
16:9 横向单图道具资产设定卡，【题材/时代】【道具名】，【归属与经历：谁在用、用了多久、经历过什么】，整体呈现真实实物摄影质感、影视道具定妆照风格。

画面分为左右两部分，用细白竖线分隔：左侧主图约占画面宽度六成；右侧约占四成，用细白横线上下均分为【三/两】格局部特写。

左侧主图：道具全貌，四分之三角度。【长条形道具从左下到右上斜放，贯穿主图对角线，两端完整入画/块状道具放在主图中央，约占主图面积七成】。道具平放在浅灰无缝背景纸上，相机从斜上方约45度俯拍，道具下方有自然接触阴影。道具在主图中尽量大，四周只留少量空白，完整不裁切。

右侧特写：每格拍的是主图里同一件道具的对应部位，造型、颜色、纹样与主图完全一致；每格是微距近摄，该部位填满格子。
第一格：【部位 + 要看清的痕迹或工艺】；
第二格：【部位 + 要看清的痕迹或工艺】；
第三格：【部位 + 要看清的痕迹或工艺】（两格时删掉）。

道具结构：【整体尺寸感 + 外形轮廓】，【各部件逐个写：如剑首、剑格、剑柄缠绳、剑身、剑鞘】。
材质与颜色：【主材质 + 颜色】，【辅材质 + 颜色】，【工艺：纹样、镶嵌、錾刻、铭文，铭文笔画模糊不可读】。
使用痕迹：【具体位置 1 + 痕迹】，【具体位置 2 + 痕迹】，【具体位置 3 + 痕迹】。

光线：主图使用大面积柔光箱均匀照明，加一道侧光勾出轮廓和表面起伏；特写格使用低角度侧光，让划痕、纹理、包浆的起伏清楚可读。金属、玉石、釉面为哑光漫反射，克制高光，包浆只在常触摸的部位微微发亮，不出现大面积镜面反光。

主图与特写统一使用干净的浅冷灰色无缝背景，背景色一致、平整，无渐变光斑，高清棚拍，真实实物摄影质感，电影级画质，轻微胶片颗粒。

负面提示词：不要等宽多栏排版，不要重复画相同视角的道具，不要特写与主图的造型、颜色、纹样不一致，不要裁切主图道具，不要主图道具过小，不要人物，不要手，不要多余道具，不要支架和展示台，不要比例尺和标注，不要可读文字，不要水印，不要3D渲染，不要游戏建模，不要CG，不要卡通，不要塑料感，不要镜面反光，不要过度锐化，不要崭新出厂感，不要背景脏污噪点，不要背景逆光光晕，不要模糊，不要低质量。
```

## 使用说明

1. **定特写格数**：默认三格；结构简单的道具（玉佩、令牌、戒指）用两格
2. **主图摆放**：剑、枪、笛、卷轴、手杖这类长条形道具斜放，占满主图对角线；印章、香炉、首饰盒、手机这类块状道具居中。带鞘、带盒的道具，主图里本体与鞘或盒平行并排、留出间隔，不要叠在一起
3. **正反面不同的道具**（令牌、铜镜、扇面、书信）：主图拍正面，其中一格特写拍背面全貌
4. **选特写部位**：先选最能说明经历的部位，再选工艺细节；不同格拍不同部位，不要重复
5. **写经历**：至少 3 处具体位置的痕迹，与道具主人的身份对得上（武将的刀柄磨亮、书生的笔杆被墨染深、富家小姐的玉佩只有极轻的佩戴磨痕）。全新道具删掉"不要崭新出厂感"，痕迹改成"出厂包装压痕、表面极细的手印"一类
6. **归档**：道具属于某个角色时，在项目看板该角色条目下记一行，后续角色定妆和镜头里沿用
7. **输出前检查**：
   - [ ] 左主图约六成宽，右侧两到三格特写，细白线分隔
   - [ ] 主图道具完整、尽量大，长条形道具斜放占满对角线
   - [ ] 每格特写写明部位和要看清的痕迹，部位不重复
   - [ ] 部件逐个写清，至少 3 处具体位置的使用痕迹
   - [ ] 金属、玉石、釉面写了哑光与克制高光
   - [ ] 无人物、无手、无文字
