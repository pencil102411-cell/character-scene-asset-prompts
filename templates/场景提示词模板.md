# 场景提示词模板

> 场景概念图、环境主视觉、建立镜头、空场景氛围图、置景空间参考的提示词正文只在本文件维护；规则原因和参数库见 `references/场景构建.md`。
> 外景用模板 F，室内用模板 G。使用时将方括号 `【】` 中的内容替换为实际参数；`【A/B】` 形式的多选项只保留一个；标"可删"的行不需要时整行删掉。
> 默认是氛围图。用户要给美术、置景看空间布局时改成空间参考图：删掉前景或近处那一行，机位改平视或略高，负面词加空间参考图追加。

---

## 场景负面词

负面词 = 通用块 + 对应追加，按顺序拼成一行。

```
不要CG感，不要游戏引擎渲染感，不要3D低模，不要贴图感远景，不要远景清晰锐利，不要均匀锐化，不要过饱和。
不要塑料感，不要油亮地面，不要大面积镜面反光。
不要可读文字，不要UI，不要水印，不要背景脏污噪点，不要过度广角畸变，不要模糊，不要低质量。
```

- 空场景追加：不要人物，不要人物剪影，不要人影，不要模糊人形。
- 在用空间追加（干净的现代室内外、宫殿官署、整洁宅院）：不要霉斑，不要墙皮剥落，不要积灰，不要锈蚀，不要废弃感。
- 空间参考图追加：不要前景遮挡，不要大面积死黑暗部，不要浓雾。

## 模板F：外景

```text
【16:9/2.39:1】横屏电影级【大全景/全景】，【平视/低角度/略俯】机位，【焦段】，【风格锚点 + 1-2 个视觉特征词】，【时段与天气】。
前景：【框景元素】，轻微虚化。（空间参考图删掉这一行）
中景：【叙事主体：建筑或地标 + 材质 + 2 处具体位置的侵蚀或生活痕迹】。
远景：【可读大形：山脉、天际线、建筑群】。
空气：【介质（薄雾/体积光/风沙/雪粉/烟尘）+ 在哪一层】。（晴天正午、现代街景改为：远处轻微的大气蓝灰和清晰度递减）
光影：【光照锚点】，【主光方向与色温】，【补光或轮廓光】。
光学质感：【1-3 项光学瑕疵，写明强度】；材质为哑光漫反射，克制高光，自然曝光滚降。
【有人物：人物位置与体量 + 设定卡里写死的参数；中远景小人物写面部哑光、柔和光，或背对、侧身。空场景：空场景，不出现人物。】
质量后缀：电影级画质，真实摄影质感，实景拍摄。
负面提示词：【通用块 + 对应追加】
```

## 使用说明

1. **定外景或室内**：外景用模板 F，室内用模板 G；半室外（回廊、阳台、天井）按主体在哪一侧选
2. **定用途**：默认氛围图；要给美术、置景看布局时改成空间参考图（见文件开头）
3. **痕迹**：古旧、废弃、荒野、简陋空间写侵蚀；有人维护、正在使用的空间（现代室内外、宫殿官署、整洁宅院）只写生活痕迹，空间整体干净（`references/场景构建.md` §4）
4. **空气**：外景大场景必须写介质；晴天正午和现代街景只写大气蓝灰；室内不写雾，只在有窗光时写浮尘
5. **光**：现代室内写清主光是哪一个，其余调暗作点缀
6. **输出前检查**：
   - [ ] 外景前中后景分层，写了空气介质；室内写了近处、主体区域、纵深
   - [ ] 痕迹类型和场景对得上，有人维护的在用空间没有霉斑、剥落、积灰
   - [ ] 光照锚点和主光方向写清
   - [ ] 空场景写了"不出现人物"，负面词带空场景追加
   - [ ] 负面提示词 = 通用块 + 对应追加
