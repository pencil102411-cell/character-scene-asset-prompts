# 角色设计

> 适用：横屏影视/游戏/动画的角色概念设计、服化道设计、单张角色图
> 核心目标：消除 AI 生成的"塑料感、大众脸、随机抽盲盒"，输出有物理存在感的角色提示词

---

## 0. 核心原则

**从"标签堆叠"走向"叙事性物理描述"**

| 弃用 | 改写 |
|------|------|
| 美女 | 细腻骨相，清晰下颌线，深邃丹凤眼略带沧桑 |
| 金属机甲 | 带有划痕与掉漆的碳纤维装甲，氧化铜色齿轮，表面附着油腻指纹 |
| 好看的裙子 | 繁复提花刺绣的宋锦，腰封边缘有细微磨损，袖口沾有干涸泥渍 |
| 古装女侠 | 青色麻布长袍边缘磨损起毛，腰间皮革束带日久发黑变硬 |

**三个关键概念：**
- **材质叙事**：材质的高级感不在于它"是什么"，而在于它"经历了什么"
- **面部差异化**：抛弃 AI 默认网红脸，用骨相参数创造独特角色
- **表面瑕疵**：打破 AI 的完美平滑，注入物理痕迹和光学瑕疵

## 1. 面部微雕参数库

根据角色性格，从以下参数组合出独特面部特征。

### 1.1 骨相底子

| 类型 | 描述 | 关键词 |
|------|------|--------|
| 精巧型 | 细腻骨相，柔和线条 | delicate bone structure, soft facial contours |
| 硬朗型 | 清晰下颌线，高颧骨 | sharp jawline, high cheekbones, lean cheeks |
| 端庄型 | 面颊饱满，天庭饱满 | full face, broad forehead, classical proportions |
| 沧桑型 | 面颊清瘦，眉骨突出 | lean weathered face, prominent brow ridge |

### 1.2 眼部神态

| 类型 | 关键词 |
|------|--------|
| 丹凤眼 | phoenix eyes, elongated upward-slanting eyes |
| 杏眼 | almond eyes, round bright eyes |
| 桃花眼 | peach-blossom eyes, naturally flirtatious gaze |
| 深邃眼窝 | deep-set eyes, heavy-lidded gaze |
| 侵略性眼神 | aggressive piercing gaze, sharp focused eyes |
| 空灵眼神 | ethereal clear gaze, distant unfocused eyes |
| 疲惫眼神 | weary eyes, slight redness, drooping lids |

### 1.3 眉形唇形

**眉形：**
| 类型 | 关键词 |
|------|--------|
| 野生剑眉 | wild sword-shaped eyebrows, thick natural brows |
| 远山柳叶眉 | distant mountain willow-leaf brows, arched delicate brows |
| 英气眉 | heroic angled brows, sharp upward brows |

**唇形：**
| 类型 | 关键词 |
|------|--------|
| 饱满微翘 | full slightly upturned lips |
| 刻薄薄唇 | thin tight lips |
| 干裂唇 | chapped dry lips with peeling skin |

### 1.4 肌肤质感

| 类型 | 关键词 |
|------|--------|
| 白皙透亮 | fair luminous skin, translucent complexion |
| 真实毛孔 | micro skin texture with realistic pores |
| 战损肌 | battle-damaged skin with dirt and scars |
| 风霜肌 | weather-beaten skin, windburnt texture |
| 油性肌（慎用） | slightly oily T-zone, visible skin texture |

> "白皙透亮"的 luminous/translucent 和"油性肌"都容易把整张脸画出油光：前者必须搭配去油词链（`references/写实质感控制.md` §二），后者只在剧情需要汗湿、油光时使用，并限定在 T 区。

### 1.5 男性面部参数

**骨相类型：**

| 类型 | 描述 | 关键词 |
|------|------|--------|
| 权贵冷峻 | 高眉骨，深眼窝，下颌利落，颧骨结构清晰 | high brow bone, deep eye sockets, sharp jawline, aristocratic coldness |
| 温润公子 | 骨相清秀端正，眉眼温和，有书卷气 | refined bone structure, gentle brows, scholarly temperament |
| 少年将军 | 清俊英气，眉眼锋利，脸部线条干净 | handsome heroic bone structure, sharp brows, clean jawline |
| 反派权臣 | 窄长脸，眉峰压低，鼻梁锋利，唇线偏薄 | narrow elongated face, lowered brow peak, sharp nose bridge |
| 侠客江湖 | 轮廓清朗，略带风尘质感，神情警觉 | clear angular contours, weather-touched skin, alert presence |

**脸型与眉眼唇**（男性设定卡模板 B 也从这里取）：
- 脸型：清俊修长 / 棱角分明 / 温润端正 / 冷峻削瘦；高眉骨、下颌线清晰、面部轮廓有真实骨骼支撑
- 眉形：修长有锋，自然黑棕/深棕，不做细弯眉
- 眼型：狭长凤眼 / 深邃瑞凤眼 / 清俊杏眼 / 锋利长眼
- 眼神：冷静压迫 / 温润克制 / 少年英气 / 沉稳深情
- 唇形：清晰但不过度饱满，自然偏淡略有血色
- 皮肤：保留毛孔细纹，可加极淡胡茬感，不要奶油肌

## 2. 服装与材质叙事

### 2.1 古装服装层次

从内到外的描述顺序：

```
内衣/中衣 → 外袍/罩衫 → 腰封/束带 → 配饰/挂件 → 鞋履
```

每层至少包含：颜色 + 材质 + 物理痕迹（磨损/褶皱/污渍）

**古装三层色叠结构与男性服饰结构：**
详见 `references/资产标准化.md` §3.2（古装三层色叠）与 §3.3（男性服饰结构+身份适配），本文件不重复列出。

**材质叙事核心规则：** 无论性别和款式，每层描述必须包含颜色+材质+物理痕迹（磨损/褶皱/污渍/氧化），使服装具备"经历过的痕迹"而非"刚出厂"的质感。

**示例：**
> 内穿白色麻布中衣领口微黄，外套褪色青灰锦缎长袍袖口磨损起毛，腰束日久发黑变硬的牛皮革带，铜扣氧化生绿，脚踩沾满干涸泥渍的布鞋

### 2.2 常见古装材质对照

| 材质 | 弃用 | 改写 |
|------|------|------|
| 丝绸 | 光滑的丝绸 | 光泽哑暗的提花缎面，经年洗涤后边缘起毛，轻微褪色不均 |
| 锦缎 | 好看的锦缎 | 繁复妆花织金的宋锦，金线已氧化发暗，局部有跳丝 |
| 纱 | 薄纱 | 层叠的云雾纱，下摆沾有泥水干涸后的硬质感 |
| 皮革 | 皮甲 | 带划痕的哑光牛皮，常摩擦处发亮包浆，金属扣件氧化 |
| 棉麻 | 麻布 | 粗糙手工夏布，染色不均的自然植物色素，洗到发软的质地 |

### 2.3 面部与服装的痕迹匹配

角色面部痕迹必须与服装痕迹一致，制造统一的人物背景故事：

| 人物设定 | 面部痕迹 | 服装痕迹 |
|---------|---------|---------|
| 长途旅行者 | 风霜肌、唇干裂、眼下乌青 | 袍角沾泥、鞋底磨损、背包肩带发亮 |
| 落魄贵族 | 眼下乌青、面色苍白、眼神疲惫 | 锦缎褪色、金线氧化、领口微黄 |
| 工匠/铁匠 | 手部老茧、面部炭灰 | 皮围裙磨损、袖口烧灼痕迹、金属屑附着 |
| 习武之人 | 眉骨旧疤痕、指节老茧 | 肩部磨损（武器摩擦）、腰带位移痕迹 |

## 3. 角色设计工作流

### 3.1 输入分析

收到用户输入后自动执行：

1. **定档位与风格**：按 `references/风格美学锚点库.md` 先定档位（默认实拍档；用户明确要写真、海报才用写真档），再选 1 个风格锚点（古典仙侠/现代都市/科幻赛博/诡异惊悚/古偶网感，古偶网感只属于写真档）
2. **骨相选择**：根据角色性格选择对应骨相参数（§1）
3. **材质编织**：按本文件 §2.3 让服装痕迹与面部痕迹匹配，具体痕迹词从 `references/材质叙事词典.md` 调取
4. **质感控制**：按 `references/写实质感控制.md` 加皮肤真实感组合与去油词
5. **输出格式化**：
   - **概念设计/视觉探索** → 自由段落式，或 SKILL.md 的"单图通用骨架"，不做四栏排版约束
   - **角色设定卡** → 填入 `templates/角色设定卡模板.md`，严格四栏排版
   - **单帧展示** → 单图通用骨架；需要精确控制五官、服装层次、光线方位时，用 `references/结构化提示词框架.md` §一 的结构化 JSON

### 3.2 输出结构

- 必须先明确输出类型（概念设计 / 角色设定卡 / 单帧展示）
- 中文为主，仅保留必要英文技术控制词
- 必须调用材质叙事词典中的痕迹描述
- 必须指定画幅（默认 16:9）
- 必须附加质量后缀和避坑词

### 3.3 常见失败修复

见 `references/写实质感控制.md` §五（面部塑料感、画面发油、网红脸、眼神死板、服装无质感等）。
