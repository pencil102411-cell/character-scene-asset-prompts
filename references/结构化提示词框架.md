# 结构化提示词框架

> 所有任务共享的可选参考。在标准模板之外，提供结构化 JSON 格式、多镜头覆盖模式、双重构图等高级框架作为备选输出方式。
> 不单独使用，配合具体任务调用。当用户输入中包含明确的参数化需求时优先使用本框架。

---

## 使用原则

- 本框架是标准模板的**补充**而非替代
- 自由文本输出优先使用模板中的段落式结构
- 当需要精确控制（发型角度、服装层次、光线方位、动作姿态）时，切换为结构化 JSON 格式
- 当需要多视图展示同一角色/场景时，使用多镜头覆盖模式
- 当需要叙事性双重画面时，使用双重构图模式

---

## 一、结构化 JSON 提示词格式

源自 Nano Banana Pro 的参数化控制体系，将提示词拆分为独立可控字段，减少 AI 的自由解读空间。能读长文本的模型（GPT-image、Nano Banana 等）可以直接粘贴 JSON；不接受 JSON 的平台，按字段顺序串成段落。

### 1.1 基础结构

```json
{
  "subject": {
    "appearance": "整体外貌描述",
    "hair": "发型：长度+颜色+质地+刘海+碎发+高光",
    "face": "脸型+骨相+眉眼+鼻梁+唇形",
    "skin": "皮肤真实感组合+去油词",
    "body_details": "身形特征"
  },
  "outfit": {
    "top": "上装：款式+材质+纹理",
    "bottom": "下装：款式+材质",
    "layer": "外套/披肩/叠穿",
    "footwear": "鞋履",
    "accessories": "配饰"
  },
  "pose": "姿态：角度+重心+手部位置+视线方向",
  "lighting": {
    "setup": "主光方位+光质+光比",
    "details": "补光/轮廓光/特殊光效"
  },
  "camera": {
    "lens": "焦段+光圈",
    "quality": "画质后缀+光学质感"
  },
  "aspect_ratio": "画幅，默认 16:9",
  "avoid": "不要……（避坑词，内联写法；平台有负面框时去掉“不要”移过去）"
}
```

字段值用中文写，只保留必要的英文技术控制词。

### 1.4 使用时机

| 适用场景 | 理由 |
|---------|------|
| 角色概念设计需要精确控制五官参数 | 结构化字段避免模型自由发挥 |
| 服装有多层结构 | 逐层描述防止 AI 合并或丢失层次 |
| 光线有复杂多层设计 | 主光/补光/轮廓光/冷暖分离逐项控制 |
| 对姿态有精确角度要求 | 结构化描述配合角度数字 |

## 二、四段式镜头覆盖模式

源自人像摄影的多景别覆盖策略。适合同一角色/场景需要用多张图展示完整面貌。

### 2.1 标准四段结构

```
图1 — 全景环境（交代空间、角色与环境的关系）
图2 — 中景半身（展示人物面部+服装细节、情绪）
图3 — 低角度/特写（独特视角、光影戏剧性、局部叙事）
图4 — 全身/环境人像（舒展姿态、自由情绪、风与动态）
```

### 2.2 四段职责

| 景别 | 核心任务 | 焦段建议 | 构图要点 |
|------|---------|---------|---------|
| **全景** | 建立空间关系、人物渺小感、环境宏大叙事 | 24mm 广角 | 人物置于三分点，与环境形成体量对比 |
| **中景** | 面部与服装细节、温柔情绪、浅景深 | 85mm 中焦 | 焦点锁双眼，背景虚化成色块 |
| **特写/低角度** | 独特视角、框式构图、逆光戏剧性 | 35mm | 前景虚化元素形成天然画框 |
| **全身** | 舒展姿态、自由情绪、风与头发互动 | 50mm 标准 | 人物置下1/3，上2/3留给天空/环境 |

### 2.3 输出格式示例

画幅默认 16:9；用户要竖版海报、社媒图时，再按需要改为 2:3、3:4、4:5。

```text
图1 — 全景环境（【画幅】）
[景别：全景/大全景]。核心：[宏大景观+人物渺小感]。
[光线描述]。[镜头参数]。[情绪目的]。

图2 — 中景半身（【画幅】）
[景别：中近景/半身]。核心：[情绪+服装细节+浅景深]。
[光线描述]。[镜头参数]。[情绪目的]。

图3 — 低角度特写（【画幅】）
[景别：特写/低角度]。核心：[独特视角+光影戏剧性+局部叙事]。
[光线描述/框景方式]。[镜头参数]。[情绪目的]。

图4 — 全身/环境人像（【画幅】）
[景别：全身/环境人像]。核心：[姿态舒展+动态元素]。
[光线描述]。[镜头参数]。[情绪目的/氛围关键词]。
```

### 2.4 适用场景

- 角色概念设计需要多角度展示
- 同一场景需要多张图做视觉探索
- 服化道需要从全景到局部逐层展示

## 三、双重构图模式

在一张画面中包含两个视觉层次，适合叙事性角色展示。

### 3.1 类型A：前景+背景投影

```
前景主体角色 + 背景同角色面部投影/剪影

前景：写实主体，具体姿态和光线
背景：同角色的静态投影/放大面部/剪影，不同色调
过渡：通过聚光灯/投影仪效果实现空间分离
叙事功能：内外对比、记忆与现实的并置
```

### 3.2 类型B：上下双帧叙事

```
上帧：近景/中近景、情绪反应、浅景深
下帧：广角/远景、环境交代、动态模糊
过渡：上下帧边界柔和模糊渐变，无缝融合
叙事功能：同一角色的两个时空瞬间、反应与环境的并置
```

### 3.3 类型C：镜面反射

```
前景：主体面向镜子，手持手机/自然姿态
镜面反射：主体背面或侧面的完整镜像
关键：镜面灰尘/指纹/轻微污渍增加真实感
叙事功能：自我审视、UGC 真实感、空间拓展
```

### 3.4 使用规范

- 双重构图中必须有一个主体是明确的视觉焦点
- 两个画面层次的光线逻辑需自洽（不能一个正光一个逆光）
- 类型A中背景投影必须与前景主体明显区分（通过色调/亮度/饱和度）
- 类型B中上下帧边界推荐使用渐变模糊而非硬切

## 五、光影冷暖分离技术（写真档专用）

源自仙侠/古装高级写真的标志性布光手法。只用于写真档（见 `references/风格美学锚点库.md` 档位表）；实拍档、设定卡、表情板不用，光照按 `references/场景构建.md` §3 和 `references/写实质感控制.md` §一 写。

### 5.1 标准配置

```
主光：大面积极柔和的暖白金美容光
  → 位置：面部正面略上
  → 作用：皮肤通透、气血感、柔和明暗过渡

轮廓光：极克制的冷蓝白轮廓光
  → 位置：头发外轮廓、顶部边缘
  → 作用：将主体从背景中分离，形成高级冷暖对比

背景：融化成发光色块/雾团
  → 色调：暖白/琥珀白/奶油色
  → 效果：柔和 bloom + 体积雾

结果：面部暖、边缘冷、背景通透
```

### 5.2 变体方案

| 主体 | 主光 | 轮廓光 | 背景 | 情绪 |
|------|------|--------|------|------|
| 仙侠/神明 | 暖白金柔光 | 冷蓝白 | 发光琥珀白雾 | 圣洁、超现实 |
| 清冷美人 | 冷白柔光 | 暖金 | 冷灰蓝雾 | 疏离、高冷 |
| 战损/沧桑 | 冷侧光 | 暖夕阳 | 深灰渐变 | 悲壮、史诗 |
| 古偶甜暖 | 暖金柔光 | 暖白 | 暖杏色散景 | 温柔、治愈 |

### 5.3 技术关键

- **主光和轮廓光色温必须差至少一个色温等级**（暖白 vs 冷蓝）才能形成有效分离
- **轮廓光的面积要克制**：只出现在边缘、发梢、肩部轮廓，不能扩展到主体正面
- **高光允许轻微梦幻式过曝**，但必须柔软泛开不能锐利
- **明暗过渡必须细腻**，不能有硬边缘
