# 场景构建

> 适用：横屏影视/游戏/动画的场景概念设计、环境主视觉、建立镜头（Establishing Shot）、空场景氛围图、置景空间参考；外景与室内、古装与现代
> 核心目标：消除 AI 的平庸视角、远景贴图感、油亮塑料感，输出电影级场景提示词
> 分工：场景提示词正文在 `templates/场景提示词模板.md`（模板 F 外景、模板 G 室内）；本文件放规则原因和参数库。

---

## 0. 核心原则

- **空间分层**：外景按前中后景分配职责——前景框景、中景叙事、远景尺度；室内按近处、主体区域、纵深分层（§1）
- **痕迹分场景类型**：古旧、废弃、荒野、战后的空间写"环境侵蚀"；有人维护、正在使用的空间（现代室内外、宫殿官署、整洁宅院）写"生活痕迹"，空间整体保持干净（§4）。完美无痕的空间显假，但给豪宅、写字楼做旧，就成了旧楼
- **光学瑕疵**：引入摄影机的物理极限，打破 AI 的完美渲染（§2）

### 0.1 两种用途

| | 氛围图（默认） | 空间参考图 |
|---|---|---|
| 用于 | 概念图、主视觉、建立镜头、空场景氛围 | 给美术、置景、分镜看空间结构和陈设 |
| 机位 | 按情绪选，可低角度、可倾斜 | 平视或略高，约 24–35mm，正对空间主轴 |
| 前景 | 可用前景框景，虚化 | 不加前景遮挡，空间结构完整可读 |
| 光 | 按时段与情绪，可以有强烈明暗 | 实景光，明暗有层次但暗部可读 |
| 空气介质 | 外景按 §1.3 | 只留轻微，不遮挡远处结构 |

用户说"置景参考""给美术看""看清布局"时用空间参考图；没说就是氛围图。

## 1. 空间分层规则

### 1.1 外景三层

| 层级 | 职责 | 常用元素 | 注意事项 |
|------|------|---------|---------|
| **前景** | 遮挡、框景、增加景深 | 枝叶、门洞、栏杆、雨丝、烟尘、岩石、纱幔 | 虚化处理，不可抢中景焦点；空间参考图不用 |
| **中景** | 叙事核心、视觉焦点 | 主体建筑、山门、街道、平台、人物 | 最高细节密度，局部高频纹理 |
| **远景** | 尺度参照、轮廓识别、氛围 | 群山、天际线、塔楼、悬崖、远殿、城市剪影 | 可读大形为主，不堆细节 |

### 1.2 室内三层

| 层级 | 职责 | 常用元素 |
|------|------|---------|
| **近处** | 交代观看位置，可轻微虚化；空间参考图不用 | 门框、屏风边缘、桌角、椅背、帘子 |
| **主体区域** | 叙事核心 | 床榻、书案、会议桌、沙发区、吧台、病床 |
| **纵深** | 让空间有出口和层次 | 窗外景、门后走廊、里间、楼梯 |

室内的纵深靠窗、门、走廊里的另一层空间，不靠雾。

### 1.3 空气透视

- **外景大场景**：中景和远景之间写一层介质拉开距离——`薄雾 / 体积雾 / 湿气 / 风沙 / 雪粉 / 光束 / 烟尘`。没有空气透视的远景 = 贴图背景
- **晴天正午、现代城市街景**：不写雾，写"远处轻微的大气蓝灰和清晰度递减"
- **室内**：不强制；有窗光时写"窗光光束里的细小浮尘"即可，不写薄雾。室内加雾会让整个画面发灰发脏

### 1.4 分层写法示例

外景：
```
前景：被夜露打湿的松针与半掩的石阙形成框景
中景：巨大的青石山门，悬挂微弱灯火的回廊，潮湿的石阶
远景：隐入薄雾的群山，层层殿宇飞檐与高处观星塔
空气层：山雾与潮气混合的稀薄体积光
```

室内：
```
近处：半开的雕花木门，门框边缘轻微虚化
主体区域：临窗的黑漆书案，案上摊开的书卷和用秃的毛笔
纵深：支摘窗外的竹影和后院回廊
空气：窗光斜照，光束里有细小浮尘
```

## 2. 光学瑕疵与静帧镜头物理感

### 2.1 光学瑕疵

完美的画面等于虚假，必须引入摄影机的物理极限。词表与强度控制见 `references/写实质感控制.md` §三，按场景情绪选 1–3 项。

### 2.2 静帧镜头物理感

图像提示词只能表现"这一帧"里看得见的镜头物理感：

| 效果 | 关键词 | 情绪作用 |
|------|--------|---------|
| 倾斜构图 | slight dutch tilt, imperfect framing | 不安、纪实感 |
| 冲击瞬间 | motion blur on moving elements, debris frozen mid-air | 混乱、战斗冲击 |
| 焦外层次 | shallow depth of field, foreground bokeh | 空间纵深 |

> 运镜词（推拉摇移、手持呼吸晃动、剧烈震动、对焦呼吸 lens breathing）属于视频，静帧提示词里不写。

## 3. 光照时空锚点

### 3.1 自然光

| 光照 | 时间 | 关键词 | 适用场景 |
|------|------|--------|---------|
| 黄金时刻 | 日出后/日落前1小时 | Golden Hour, warm amber light, golden sunlight | 唯美、史诗、温馨 |
| 蓝调时刻 | 日落后的暮色/日出前 | Blue Hour, cool ethereal light, blue twilight | 清冷、仙侠、刺客潜伏 |
| 阴天漫射 | 阴天/雾天 | overcast diffuse light, soft even lighting | 压抑、日常、悬疑 |
| 正午硬光 | 晴天中午 | harsh midday sun, hard shadows, high contrast | 燥热、荒漠、紧张、现实主义 |
| 雨天 | 阴雨白天 | rainy overcast light, wet ground, soft diffuse light | 压抑、离别、悬疑 |
| 雨夜 | 夜晚下雨 | rainy night, wet streets reflecting lights, light rain streaks | 都市夜戏、悬疑、追逐 |
| 雪天 | 下雪/雪后 | overcast snow light, soft bounce light from snow | 清冷、肃杀、静谧 |
| 月光夜 | 夜晚 | cold moonlight, silver-blue night light | 神秘、危险、修仙 |

> 雨天、雨夜的反光只出现在积水和湿漉的表面，是破碎、不规则的倒影，不是整片镜面。

### 3.2 室内光

| 光照 | 场景 | 关键词 | 情绪 |
|------|------|--------|------|
| 室内烛火 | 古装夜间室内 | warm candlelight, warm lantern glow | 亲密、压抑 |
| 窗光 | 白天室内 | soft window light, side light from window | 日常、文戏 |
| 办公室顶灯 | 现代写字楼、医院 | cool overhead LED panel light | 职场、冷漠、疏离 |
| 暖色家居灯 | 现代住宅夜间 | warm practical lamps, pools of light | 温情、私密 |
| 霓虹与屏幕光 | 酒吧、夜店、电竞房 | neon signs, screen glow on surfaces | 暧昧、迷离 |
| 路灯 | 都市夜街 | sodium street lights, cool LED street lights | 夜戏、孤独 |

现代室内常是多个光源混在一起：写清主光是哪一个，其余调暗作点缀，不要每个光源都一样亮。

### 3.3 光影结构词

```
主光源方向：侧光 / 逆光 / 顶光 / 底光 / 前光
辅助光源：补面光 / 边缘轮廓光 / 环境反光
对比结构：暖主光+冷补光 / 冷主光+暖点缀
```

## 4. 材质痕迹

痕迹写在 2–3 个具体位置，不要满屏平均撒。痕迹词见 `references/材质叙事词典.md`。

### 4.1 环境侵蚀（古旧、废弃、荒野、简陋）

| 场景类型 | 侵蚀描述 |
|---------|---------|
| 古建筑 | 苔藓斑驳的石阶，接缝长草，瓦片残缺，木柱褪色开裂，铜铃氧化生绿 |
| 废弃空间 | 墙角渗水霉变，蜘蛛网积灰，油漆剥落露出底层，地面积水反光 |
| 市井街道 | 青石板路被行人磨圆的边角，店招褪色，门槛踩踏凹陷 |
| 战场/破坏后 | 焦土裂痕，断裂兵器残留，烟火熏黑的墙体，碎石散落 |
| 自然野地 | 覆满落叶的山道，藤蔓爬满残垣，溪石圆润光滑 |
| 简陋居所 | 土墙墙皮剥落露出草筋，墙角水渍霉斑，泥地被踩得发亮压实，窗纸发黄破角，家具掉漆 |

### 4.2 生活痕迹（有人维护、正在使用的空间，室内外都算）

| 场景 | 生活痕迹 |
|------|---------|
| 现代办公室 | 桌上半杯冷掉的咖啡，文件边角卷起，椅子没推回桌下，地毯在常走的路线上颜色略浅 |
| 豪宅、高级公寓 | 沙发靠垫有坐过的压痕，茶几上随手放的书，石材台面有极淡的杯印，地毯绒毛有走动的方向 |
| 医院 | 病床护栏的漆边被磨白，床头柜上的水杯和药盒，走廊地胶有推车留下的浅痕 |
| 酒吧、餐厅 | 吧台木面被杯底磨出的浅圈，皮质卡座边缘发亮，墙上海报边角翘起 |
| 普通住宅 | 玄关鞋子没摆齐，冰箱上贴着便签，窗台有一盆半干的绿植，门把手周围的墙面略脏 |
| 古装宅院室内 | 书案边角被手肘磨亮，地砖在门槛到座位的路线上磨得更平，帐幔下摆轻微褪色 |
| 现代街道、广场 | 地砖在常走的路线上颜色略浅，花坛石材边角有细小磕痕，路边停放的单车，垃圾桶边缘有擦痕 |
| 宫城、官署外景 | 御道石板被踩出浅浅的凹路，台阶边角磨圆，宫灯灯罩边缘熏黄，门环一圈颜色更深 |

生活痕迹之外，空间整体保持干净整洁。豪宅、写字楼、酒店不写霉斑、剥落、积灰、锈蚀。

## 5. 横屏大全景专用控制

### 5.1 画幅与构图

- 默认画幅：16:9 或 2.39:1
- 横屏电影级建立镜头必须明确：前中后景分层、空气透视（外景）、可读大形

### 5.2 去油材质控制

场景同样必须加去油控制词，并排除禁用词（含场景专属的 flat distant background），见 `references/写实质感控制.md` §二。

## 6. 场景构建工作流

1. **定用途**：氛围图还是空间参考图（§0.1）
2. **定风格锚点**：从 `references/风格美学锚点库.md` 选 1 个。场景图默认实拍档，优先选择前 4 种（现代都市分街头和精致都市两种变体）；古偶网感属于写真档，仅用于角色宣传照类场景
3. **空间分层**：外景按 §1.1，室内按 §1.2；空气介质按 §1.3
4. **痕迹**：古旧、废弃、荒野、简陋空间按 §4.1 侵蚀；有人维护、正在使用的空间（室内外都算）按 §4.2 生活痕迹
5. **光影设定**：选光照锚点（§3.1 自然光 / §3.2 室内光）+ 光源方向
6. **光学瑕疵**：根据场景情绪选择瑕疵类型（§2）
7. **输出**：填 `templates/场景提示词模板.md`，外景用模板 F，室内用模板 G；负面词用模板里的场景通用块 + 对应追加

### 6.1 场景里有人物时

- **人物参数**：已有设定卡的角色，沿用卡里写死的面部、服装、发型参数；没有的从 `references/角色设计.md` 取
- **位置与体量**：写清人物在画面中的位置（三分点）和与环境的体量对比
- **中远景小人物**：脸在画面里很小时，不写毛孔、细纹词链，也不让侧逆光打在小脸上，改写面部哑光、柔和光；或让人物背对、侧身、低头看手里的东西。小脸写满皮肤细节反而出油、出 AI 脸（`references/写实质感控制.md` §2.4）
- **空场景**：末尾写"空场景，不出现人物"，负面词加空场景追加项；风格注入只用风格词，不带汉服、服装类题材词

## 7. 场景多镜头覆盖模式

当同一场景需要多张图展示全貌时，使用四段式镜头覆盖模式（详见 `references/结构化提示词框架.md` §二）。

### 7.1 场景专用四段职责

| 镜头 | 景别 | 核心任务 | 焦段 |
|------|------|---------|------|
| 图1 | 全景/大全景 | 建立空间、体量对比、环境叙事 | 24mm 广角 |
| 图2 | 中景 | 场景核心区域细节、材质叙事 | 50mm 标准 |
| 图3 | 低角度/特写 | 局部材质、环境侵蚀细节、光影戏剧性 | 35mm 或 微距 |
| 图4 | 中全景/环境 | 氛围收束、空间余韵、开阔感 | 24-35mm |

### 7.2 使用时机

- 场景概念设计需要从宏观到微观展示
- 用户需要多张不同角度的场景氛围图
- 场景中既有大空间叙事又有局部材质细节需要表现
