# 资产标准化

> 适用：古装/古偶/仙侠/权谋/宅斗/历史言情人物资产设定卡、定妆照、表情板（非古装题材见 §8.3）
> 核心目标：生成真人摄影质感、影视定妆照级别、角色一致性强的资产设定卡

---

## 0. 核心原则

**资产标准化是整个工业级工作流的第二步。**

```
概念定调（风格锚点） → 资产标准化（设定卡锁定角色） → 物理与光学注入（最终成片）
```

**核心逻辑**：角色在进入正式场景之前，必须先在一张资产卡上锁定面部特征、三视图身形比例、服装结构和材质参数。后续所有镜头和场景都以这张卡为锚点，确保脸不飘、妆不换、衣不乱。

**核心目标：**
- 消除脸部 AI 感、塑料感、过度磨皮
- 妆容有真实气血和古偶精致度
- 服装/首饰不像塑料、影楼服、廉价 cosplay
- 多视图脸一致、头身比标准（约1:7.5，不出大头）
- 全身照小脸不出油，背景干净不显脏

## 1. 四栏排版规范

### 1.1 标准布局

```
┌──────────┬──────────────┬──────────────┬──────────────┐
│  第一栏   │   第二栏      │   第三栏      │   第四栏      │
│ 面部极致  │   正面全身    │   背面全身    │  正侧面全身   │
│ 特写正面照 │   站立照      │   站立照      │  （90度）     │
│          │              │              │   站立照      │
└──────────┴──────────────┴──────────────┴──────────────┘
              16:9 宽屏 / 纯白或浅灰白干净背景
```

**强制约束：**
- 所有视图必须是同一个人物：同一张脸、同一骨相、同一五官比例、同一眉眼、同一鼻梁、同一唇形、同一妆容、同一发型、同一服饰体系
- 三张全身照严格等身高、等比例、等大小：头顶线对齐、脚底线对齐，从头顶到鞋底完整入画，脚下留少量空白
- 纯白或浅灰白干净背景，不可出现可读文字、UI、水印
- 横向四栏，不做上下分区：上下两层结构容易让模型把内容做错位或做成缩略图。负面词里明确写"不要上下两层排版"后，模型乱排的概率大幅下降——排版必须靠负面词一起约束

### 1.2 头身比与镜头规范（防大头）

头稍大、头身比失调的两个主要诱因：一是设定卡窄栏构图挤压全身，模型倾向放大头部保脸部细节；二是隐含的广角/仰拍透视让头肩变大。提示词必须同时封堵：

```
标准成年真人身材比例，头身比约1:7至1:7.5（男性取1:7.5），
头部大小与肩宽比例正常，颈肩过渡自然。
全身照以平视约50mm中焦镜头拍摄，相机高度位于人物胸腰之间，
无广角畸变，无仰拍俯拍透视，头部不因透视或构图被放大。
```

**负面词配套：** 不要大头，不要头身比失调，不要头部放大，不要Q版比例，不要儿童身材比例，不要广角畸变，不要仰拍透视

### 1.3 跨视图脸部一致性（防换脸）

**根因**：全身照中头部仅占画面极小区域，模型是"重新画一张小脸"而不是"缩小复制特写脸"。纯文字约束只能降低漂移概率，不能根除。

**提示词层（缓解）：**
```
第一栏面部特写是整张卡的脸部锚点。
第二、三、四栏全身照的头部虽小，五官仍必须与第一栏特写完全一致，
如同一位真人演员在同一次定妆拍摄中的不同机位照片。
侧面照的额头-鼻梁-唇-下颌轮廓线必须与正脸骨相吻合。
```

**工作流层（实操策略）：**
1. 单张直出，不使用参考图锁脸——实测参考图会继承原图的噪点和色调、把画面搞脏，而且锁不住全身照里小尺寸头部的五官
2. 降低漂移的主要手段是把面部参数写死写具体：脸型、骨相、眼型、鼻梁、唇形全部用明确参数，不留模糊词
3. 生成后逐栏对比五官；漂移则直接重 roll 整卡
4. 接受天花板：全身照头部像素少，一致性只能逼近、无法百分百，后续镜头以第一栏特写为脸部标准

## 2. 第一栏：面部极致特写正面照

### 2.1 目标

建立角色最核心的脸部资产，确保后续三张全身照（及独立表情板）都围绕这张脸保持一致。第一栏不够清晰或有遮挡时，多视图脸不一致的概率明显上升。

### 2.2 写法标准

```
超真实真人写真摄影，微距完整正脸特写，正面面对镜头，视线看向镜头或略微偏离镜头，
不低头，不仰头，不侧脸，不遮挡，不切半张脸。

东方古典美人/男性骨相：【脸型】+【骨相类型】+【真实骨骼结构】

眼型：【类型】+【眼神】，眼神自然不呆滞
鼻梁：【形状】+【鼻头】
唇形：【类型】+【唇色】

皮肤保留真实毛孔、细纹、细小汗毛、面中自然薄红、鼻翼和眼下轻微肤色变化。
不要磨皮，不要蜡像，不要塑料肌肤。

（本栏专用光）真实侧逆光，面部有明确明暗变化，非均匀受光。
轻微光影颗粒、灰尘噪点、极轻微色差、胶片颗粒。
```

## 3. 第二至四栏：正面、背面、侧面全身

### 3.1 通用要求

三栏保持一致的脸、一致的气质、一致的服饰体系，等身高等比例站立（见 §1.2 头身比规范），光线按 §7.1 改用柔光。

正面展示身形、服饰正面、发型、首饰；背面展示发髻结构、披发长度、后背衣片、腰封背面、裙摆层次；侧面为严格90度正侧站立、面朝画面左侧（不要四分之三侧面、不要回头看镜头），展示侧脸轮廓线（额头-鼻梁-唇-下颌连贯自然，与正脸骨相吻合）、发髻/发冠侧面结构、服装侧面层叠关系、披帛或衣摆垂落走向、腰封侧面厚度。

### 3.2 古装三层色叠结构

```
内层 — 月白软缎 / 宋锦 / 素纱 / 暗纹罗纱，有细腻织纹
中层 — 交领长裙 / 对襟长衫 / 窄袖长袍，领口袖口腰封有滚边
外层 — 轻纱披帛 / 薄绢外衫 / 纱罗罩衫，清透有空气感
```

**滚边颜色：** 极浅杏色 / 淡藕粉 / 暖白 / 银灰 / 浅香槟
**刺绣要求：** 低饱和银线、暖白线、浅香槟金线或同色暗线，绣纹织进布料里，不要亮片感

### 3.3 男性服饰结构

```
内层 — 细密暗纹中衣或软缎里衣
中层 — 交领长袍 / 圆领袍 / 窄袖劲装
外层 — 暗纹外袍 / 大氅 / 罩衫 / 轻甲外披
```

**身份适配：**
- 王爷/帝王：玄青墨蓝层叠长袍，银线云纹/龙纹刺绣
- 少年将军：窄袖劲装，束腰革带，哑光护腕
- 温润公子：月白竹青交领长袍，简洁腰封
- 反派权臣：深墨鸦青窄袖长袍，暗纹克制
- 侠客江湖：灰青褐色劲装，风尘磨损质感

### 3.4 织物真实感

服装质感靠材质的物理描述，不靠品类名称——"高级汉服"无效。所有衣料必须包含：
```
真实织物纤维、细密织纹、自然褶皱、柔软垂坠、袖缘轻微磨砂、腰封压痕、裙摆细小毛边、暗纹织进布料里、刺绣线迹可见
```

**避免：** 塑料薄膜感、亮片塑料、过度反光、廉价影楼服、cosplay质感、贴图刺绣

## 4. 表情板（独立任务）

> 标准四栏设定卡不含微表情列（第四栏是侧面全身）。只有用户明确要"表情板/表情图"时，才作为独立单图输出。

### 4.1 规则

- 同一人物 6-8 个表情格网格排列，所有表情保持同一张脸、同一妆容、同一发型、同一肤质
- 单张直出、面部参数写死，不使用参考图（原因见 §1.3）
- 保持真人比例：即使崩溃大哭也是同一张脸的真实表情。漫画颜艺、五官崩坏会让该格看起来不像同一个人

### 4.2 表情板骨架

```text

面部参数（与设定卡第一栏一致，写死）：【脸型】，【骨相】，【眼型】，【眉形眉色】，【鼻梁】，【唇形唇色】。

第1格【表情名】：【表情描述，取自 §4.3】

所有表情保持真人比例；皮肤保留毛孔、细纹与自然肤色变化，面部哑光无油光。纯白或浅灰白干净背景。

负面提示词：不要漫画颜艺，不要五官崩坏，不要表情格之间换脸，不要各格发型妆容服装不一致，不要格内文字标签，不要水印，不要塑料皮肤，不要面部油光。
```

### 4.3 微表情库（按需选 6-8 个）

#### 泪水滑落
一滴眼泪从眼角滑下，泪痕沿脸颊缓慢下落，鼻尖泛红，眼神向下不看镜头，嘴角微微下垂。眼眶微红，睫毛有轻微湿意。

#### 崩溃大哭
双眼紧闭，泪水大量涌出，嘴巴张开哭喊状，眉心紧皱，鼻尖和眼尾泛红，脸部肌肉有真实拉扯感。保持真人比例，不漫画化。

#### 怀疑警惕
眼神眯起，瞳孔收缩，头微微向后退，眉峰轻压，嘴唇轻抿，眼神从侧前方观察，不死盯镜头。

嘴角微微上扬，眼睛弯成月牙，脸颊有淡淡笑纹，笑容自然含蓄，不露齿或只微微露齿。

## 5. 妆容质感规则

妆造不能只写"漂亮""精致妆容"——这类写法输出不稳定。必须拆到眉色、眼妆、唇色、面中气血和发型结构。

### 5.1 古偶女主淡妆

```
眉色柔和灰棕，不要黑硬眉
眼妆加入极淡暖棕/杏粉/浅玫瑰/烟粉色晕染，只在眼尾和卧蚕
面中自然薄红，像真实皮肤透出的气血感
唇色为柔和豆沙玫瑰/淡山茶红/柔雾朱砂红/浅杏红，微润不油亮
```

### 5.2 男性影视妆造

```
底妆真实克制，保留皮肤纹理、毛孔、细小汗毛
眉形修长有锋，眉色自然黑棕或深棕
眼部只做极轻阴影修容，增强眉骨、眼窝和鼻梁层次
唇色自然偏淡，不涂明显口红
```

**男性禁止：** 杏粉眼影、豆沙玫瑰唇、腮红、闪粉、男团浓妆、奶油肌

### 5.3 冷清人物加暖方式（小面积调整）

冷清/疏离型角色需要气血感时，只做小面积加温；大面积改色会偏离角色设定。

唇色加一点玫瑰/山茶/杏红 → 眼妆加极淡暖棕/杏粉 → 面中薄红稍微增强 → 服装滚边加入浅杏/淡藕粉/暖白 → 刺绣加入极浅香槟金或暖白线 → 首饰用暖白玉/米珠

## 7. 光学与摄影质感规则

### 7.1 分栏光照（防全身照小脸出油）

**第一栏特写：** 真实侧逆光，面部有明确明暗变化，非均匀受光。眼窝、鼻侧、唇下、下颌有真实阴影层次。

**第二至四栏全身：** 大面积柔光箱均匀柔和照明；全身照面部为哑光粉感（matte powdered skin finish），无成片反光，额头、鼻梁、颧骨没有高光斑。负面补"不要全身照面部油光，不要额头鼻梁高光过曝"。

**为什么分栏：** 去油词（毛孔、matte diffuse）需要足够像素才能渲染，全身照的小脸画不下微纹理，模型会退化成"光滑 + 高光"；特写用的侧逆光落在小脸上，又会糊成额头-鼻梁-颧骨连片高光斑。实测按栏分光后油光明显消退；只能压制无法根除，五官一致即达标。

### 7.2 质感分寸

```
真实真人摄影质感，【古偶电视剧定妆照 / 电影级古装定妆照】风格
轻微光影颗粒、灰尘噪点、极轻微色差、胶片颗粒、轻微暗角——只作为人物的摄影质感

```

**不要写"不要干净无层次"：** 实测这句会让整张设定卡显脏。设定卡需要干净背景和清楚结构，层次来自特写栏的侧逆光和皮肤细节。

**风格选择：** 网剧/短剧宣传取"古偶电视剧定妆照"；严肃影视、电影感项目取"电影级古装定妆照"（与 `references/风格美学锚点库.md` 古偶/网感的使用限制一致）。

## 10. 与角色设计的区分

| 维度 | 角色设计（references/角色设计.md） | 资产标准化（本文件） |
|------|----------------------|-------------------|
| 输出目的 | 概念定调 / 视觉探索 | 锁定角色资产 / 可复用参数 |
| 画面构图 | 自由构图，可融入场景 | 固定四栏排版，纯白或浅灰白背景 |
| 角色姿态 | 可做动作表情 | 统一站立三视图（正/背/侧） |
| 风格自由度 | 高 | 低（写实摄影风） |
| 输出用途 | 看"感觉"对不对 | 后续视频/分镜复用 |

**适用判断：** 先做角色概念设计确认方向，再做资产标准化锁定参数。
