# 资产标准化

> 适用：古装/古偶/仙侠/权谋/宅斗/历史言情人物资产设定卡、定妆照、表情板（非古装题材见 §8.3）
> 核心目标：生成真人摄影质感、影视定妆照级别、角色一致性强的资产设定卡
> 分工：设定卡的提示词正文只在 `templates/角色设定卡模板.md` 维护；本文件只放规则的原因、参数库和负面词清单（§9），不重复写提示词段落。

---

## 0. 核心原则

**资产标准化是整个工业级工作流的第二步。**

```
概念定调（风格锚点） → 资产标准化（设定卡锁定角色） → 物理与光学注入（最终成片）
```

**核心逻辑**：角色在进入正式场景之前，必须先在一张资产卡上锁定面部特征、三视图身形比例、服装结构和材质参数。后续所有镜头和场景都以这张卡为锚点，确保脸不飘、妆不换、衣不乱。

**核心目标：**
- 消除脸部 AI 感、塑料感、过度磨皮
- 妆容有真实气血和古偶精致度
- 服装/首饰不像塑料、影楼服、廉价 cosplay
- 脸只在第一栏出现一次，而且要大：正面、侧面全身去头，背面不露脸，从构图上避开全身照小脸换脸、出油
- 三栏全身同大小、同比例，八至九头身的修长演员身材，不出大头、不显矮
- 四栏统一浅冷灰背景，干净不显脏

## 1. 四栏排版规范

### 1.1 标准布局

```
┌─────────────┬────────────┬────────────┬────────────┐
│   第一栏     │   第二栏    │   第三栏    │   第四栏    │
│  面部大特写   │  正面全身   │ 正侧面全身  │  背面全身   │
│ 脸占栏宽七成  │  （去头）   │ （90度）    │  （带头）   │
│ 上沿裁到发际线 │ 头部位置留空 │ 头部位置留空 │ 头顶到鞋底  │
└─────────────┴────────────┴────────────┴────────────┘
  16:9 宽屏 / 第一栏约三成宽，其余等宽 / 细白分隔线 / 统一浅冷灰背景
```

**强制约束：**
- 四栏是同一个人物：第一栏给脸，第二至四栏是同一身材、同一套服装；第四栏的发色、发型、发饰与第一栏一致
- 第一栏是面部大特写：脸部占栏宽七成左右，画框上沿裁在额头发际线上方，头顶可以出画，下沿到锁骨
- 第二、三栏去头：头部从颈部中段起被干净抹去，颈部以上是与背景相同的空白，领口完整保留
- 去头不等于放大：第二、三栏人物与第四栏同一大小、同一站位高度，三栏肩线对齐、脚底线对齐，头部原本的位置留空
- 三栏鞋底完整入画，脚下留少量空白，鞋子不贴底边，人物占栏高约九成
- 四栏统一干净的浅冷灰色无缝背景，不可出现可读文字、UI、水印。浅色服装（月白、素纱）放在纯白底上边缘会发虚，浅灰底能拉开轮廓
- 横向四栏，不做上下分区：上下两层结构容易让模型把内容做错位或做成缩略图。负面词里明确写"不要上下两层排版"后，模型乱排的概率大幅下降——排版必须靠负面词一起约束

### 1.2 身材比例与镜头规范（防大头）

头稍大、头身比失调的两个主要诱因：一是设定卡窄栏构图挤压全身，模型倾向放大头部保脸部细节；二是隐含的广角/仰拍透视让头肩变大。现在只有第四栏背面带头，但身材比例三栏都要锁。

**定妆卡要的是演员身材，按八至九头身写。** 测试中写"标准成年真人身材比例、头身比1:7至1:7.5"，出来的人物只有约六头身，偏矮、腿短：一是"标准"会把身材拉向普通人平均值；二是单写一个比例数字约束力弱，要同时写腿长、腰线、颈长这些看得见的特征。宽袖、披帛、多层纱裙会横向撑开轮廓，也要写明服装垂直下落。机位放在人物腰部高度，50mm 平视，既不畸变，也比胸口高度更显腿长。

写法见模板"三栏全身照是同一人物、同一身材"一段；对应负面词在 §9 的比例两行。

### 1.3 为什么正面、侧面全身去头（防换脸、防小脸出油）

**根因**：全身照中头部仅占画面极小区域，模型是"重新画一张小脸"而不是"缩小复制特写脸"，于是换脸；小脸画不下毛孔，去油词失效，于是出油；模型为了保脸部细节，又会把头画大。纯文字约束只能降低概率。

**做法**：脸只在第一栏出现一次，并且拍成大特写。第二、三栏去头，第四栏背对镜头不露脸，三个问题从构图上避开。

**提示词写法**：写"头部从颈部中段起被干净抹去，颈部以上是与背景相同的空白，领口完整保留"，并且明确"与第四栏同一大小、肩线脚底线对齐，头部原本的位置留空"；负面补"第二、三栏不要出现下巴、嘴唇或面部任何部分，第二、三栏人物不要放大，不要填满栏高"。

**不要用画框裁切的写法**（"画框上沿切在下巴下方"）：测试中模型会露出下巴和下唇，还会把人物放大填满栏高，三栏大小对不上，鞋子也贴到底边。

**跨栏一致性**：第一栏和第四栏的发色、发型、发饰一致；第二至四栏是同一身材、同一套服装，正面看到的滚边、刺绣、腰封要在侧面和背面接得上。

**工作流：**
1. 单张直出，默认不使用参考图锁脸——GPT-image 上实测参考图会继承原图的噪点和色调、把画面搞脏。换用 Nano Banana 等擅长靠参考图保持人物的模型时，用同一提示词做有参考图 / 无参考图的小批量对比再定
2. 面部参数写死写具体：脸型、骨相、眼型、鼻梁、唇形全部用明确参数，不留模糊词，后续表情板和镜头以第一栏为脸部标准
3. 第一栏脸太小、第二三栏露出下巴或人物被放大、第四栏回头露脸，直接重 roll 整卡

## 2. 第一栏：面部极致特写正面照

### 2.2 写法标准

写法见模板"第一栏是整张卡唯一露脸的一栏"一段。要点：取景是大特写（脸占栏宽七成、上沿裁到发际线上方）；脸型、骨相、眉、眼、鼻、唇逐项写具体参数（§2.3、§2.4）；皮肤按 `references/写实质感控制.md` §一 的特写组合；光线按 §7.1。

## 3. 第二至四栏：正面（去头）、侧面（去头）、背面全身

### 3.1 通用要求

三栏是同一身材、同一套服装、同一大小（见 §1.2），去头方式见 §1.1，光线按 §7.1 用柔光。

- **第二栏正面（去头）**：展示领口交叠、服饰正面、腰封正面、裙摆或衣摆、鞋履、项链腰佩一类身前首饰
- **第三栏正侧面（去头）**：严格90度正侧站立、面朝画面左侧，不要四分之三侧面；展示服装侧面层叠关系、披帛或衣摆垂落走向、腰封侧面厚度、身体侧面轮廓
- **第四栏背面（带头）**：完全背对镜头，不回头，不露侧脸；展示发髻或发冠结构、披发或束发长度、发饰背面、后背衣片、腰封背面、裙摆层次

第一栏大特写会裁掉头顶，发髻、发冠的结构主要靠第四栏背面交代；侧面结构不再单独展示。

### 3.2 古装三层色叠结构

```
内层 — 月白软缎 / 宋锦 / 素纱 / 暗纹罗纱，有细腻织纹
中层 — 交领长裙 / 对襟长衫 / 窄袖长袍，领口袖口腰封有滚边
外层 — 轻纱披帛 / 薄绢外衫 / 纱罗罩衫，清透有空气感
```

**滚边颜色：** 极浅杏色 / 淡藕粉 / 暖白 / 银灰 / 浅香槟
**刺绣要求：** 低饱和银线、暖白线、浅香槟金线或同色暗线，绣纹织进布料里，不要亮片感

### 3.3 男性服饰结构

```
内层 — 细密暗纹中衣或软缎里衣
中层 — 交领长袍 / 圆领袍 / 窄袖劲装
外层 — 暗纹外袍 / 大氅 / 罩衫 / 轻甲外披
```

**身份适配：**
- 王爷/帝王：玄青墨蓝层叠长袍，银线云纹/龙纹刺绣
- 少年将军：窄袖劲装，束腰革带，哑光护腕
- 温润公子：月白竹青交领长袍，简洁腰封
- 反派权臣：深墨鸦青窄袖长袍，暗纹克制
- 侠客江湖：灰青褐色劲装，风尘磨损质感

### 3.4 织物真实感

服装质感靠材质的物理描述，不靠品类名称——"高级汉服"无效。所有衣料必须包含：
```
真实织物纤维、细密织纹、自然褶皱、柔软垂坠、袖缘轻微磨砂、腰封压痕、裙摆细小毛边、暗纹织进布料里、刺绣线迹可见
```

**避免：** 塑料薄膜感、亮片塑料、过度反光、廉价影楼服、cosplay质感、贴图刺绣

## 4. 表情板（独立任务）

> 标准四栏设定卡不含微表情列（第四栏是背面全身）。只有用户明确要"表情板/表情图"时，才作为独立单图输出。

### 4.1 规则

- 同一人物 6-8 个表情格网格排列，所有表情保持同一张脸、同一妆容、同一发型、同一肤质
- 单张直出、面部参数写死，默认不使用参考图（原因和例外见 §1.3）
- 保持真人比例：即使崩溃大哭也是同一张脸的真实表情。漫画颜艺、五官崩坏会让该格看起来不像同一个人

### 4.2 表情板骨架

```text
横向单图角色表情板，【角色名】，【2×4 / 2×3】网格共【8 / 6】格，每格为同一角色的胸像近景：同一张脸、同一骨相、同一妆容、同一发型、同一服装领口、同一肤质，同一机位与同一柔和侧光，只有表情变化。

面部参数（与设定卡第一栏一致，写死）：【脸型】，【骨相】，【眼型】，【眉形眉色】，【鼻梁】，【唇形唇色】。

第1格【表情名】：【表情描述，取自 §4.3】
第2格【表情名】：【表情描述】
……（按格数写全）

所有表情保持真人比例；皮肤保留毛孔、细纹与自然肤色变化，面部哑光无油光。纯白或浅灰白干净背景。

负面提示词：不要漫画颜艺，不要五官崩坏，不要表情格之间换脸，不要各格发型妆容服装不一致，不要格内文字标签，不要水印，不要塑料皮肤，不要面部油光。
```

### 4.3 微表情库（按需选 6-8 个）

#### 泪水滑落
一滴眼泪从眼角滑下，泪痕沿脸颊缓慢下落，鼻尖泛红，眼神向下不看镜头，嘴角微微下垂。眼眶微红，睫毛有轻微湿意。

#### 崩溃大哭
双眼紧闭，泪水大量涌出，嘴巴张开哭喊状，眉心紧皱，鼻尖和眼尾泛红，脸部肌肉有真实拉扯感。保持真人比例，不漫画化。

#### 瞳孔地震
瞳孔剧烈收缩，眼睛睁大，嘴巴微张，面部瞬间僵硬，眉毛轻微上抬，呼吸停住的感觉，脸色略微发白。

#### 怀疑警惕
眼神眯起，瞳孔收缩，头微微向后退，眉峰轻压，嘴唇轻抿，眼神从侧前方观察，不死盯镜头。

#### 自然微笑
嘴角微微上扬，眼睛弯成月牙，脸颊有淡淡笑纹，笑容自然含蓄，不露齿或只微微露齿。

#### 灿烂大笑
嘴巴张开露齿，眼睛眯成缝，眼角有笑纹，笑容明亮真实，不要夸张大嘴。

#### 宠溺笑
嘴角温柔上扬，眼角细纹微微出现，眼神柔软偏侧，不直接死盯镜头。

#### 眉头紧锁
眉毛向下压成倒八字，眼神锋利，嘴唇抿紧，下巴微收，表情冷静压迫。

#### 隐忍含泪
眼眶湿润但泪水未落，鼻尖微红，嘴唇轻轻抿住，眼神克制。

#### 轻蔑冷笑
一侧嘴角极轻微上扬，眼神下压，眉尾微挑，带锋芒但不夸张。

#### 惊喜愣住
眼睛微微睁大，嘴唇轻启，眉毛轻抬，脸上有短暂失神和温柔惊喜。

#### 男性泪水滑落（克制版）
眼眶泛红但强忍情绪，一滴泪从眼角滑下，下颌绷紧，唇线压住，眼神低垂。

#### 男性崩溃大哭（克制版）
双眼紧闭，泪水涌出，眉心紧皱，下颌和颈部肌肉绷紧，有失控感但不漫画化。

## 5. 妆容质感规则

妆造不能只写"漂亮""精致妆容"——这类写法输出不稳定。必须拆到眉色、眼妆、唇色、面中气血和发型结构。

### 5.1 古偶女主淡妆

```
眉色柔和灰棕，不要黑硬眉
眼妆加入极淡暖棕/杏粉/浅玫瑰/烟粉色晕染，只在眼尾和卧蚕
面中自然薄红，像真实皮肤透出的气血感
唇色为柔和豆沙玫瑰/淡山茶红/柔雾朱砂红/浅杏红，微润不油亮
```

### 5.2 男性影视妆造

```
底妆真实克制，保留皮肤纹理、毛孔、细小汗毛
眉形修长有锋，眉色自然黑棕或深棕
眼部只做极轻阴影修容，增强眉骨、眼窝和鼻梁层次
唇色自然偏淡，不涂明显口红
```

**男性禁止：** 杏粉眼影、豆沙玫瑰唇、腮红、闪粉、男团浓妆、奶油肌

### 5.3 冷清人物加暖方式（小面积调整）

冷清/疏离型角色需要气血感时，只做小面积加温；大面积改色会偏离角色设定。

唇色加一点玫瑰/山茶/杏红 → 眼妆加极淡暖棕/杏粉 → 面中薄红稍微增强 → 服装滚边加入浅杏/淡藕粉/暖白 → 刺绣加入极浅香槟金或暖白线 → 首饰用暖白玉/米珠

## 7. 光学与摄影质感规则

### 7.1 分栏光照

**第一栏特写：** 真实侧逆光，面部有明确明暗变化，非均匀受光。眼窝、鼻侧、唇下、下颌有真实阴影层次；面部哑光漫反射，无油光。逆光只勾发丝和脸颊轮廓，背景保持与其余三栏一致的浅灰，不出现光晕和泛白雾气（测试中出现过，会让第一栏和其余三栏不像同一次拍摄）。

**第二至四栏全身：** 大面积柔光箱均匀柔和照明，服装材质、褶皱、刺绣和层叠关系清楚可读。

**为什么分栏：** 脸部层次靠侧逆光；全身栏的任务是看清服装，侧逆光会让暗部吞掉衣服结构。旧版四栏全身都带头时，侧逆光落在小脸上会糊成额头-鼻梁-颧骨连片高光斑，这个问题现在由去头构图避开（§1.3）；客户给的旧版带头四栏卡出油时，按 `references/写实质感控制.md` §2.4 处理。

### 7.2 质感分寸

颗粒、噪点、色差只写"轻微"，只作为人物的摄影质感；背景保持干净的浅冷灰，层次来自特写栏的侧逆光和皮肤细节。真实与脏的分寸见 `references/写实质感控制.md` §四。

**风格选择：** 网剧/短剧宣传取"古偶电视剧定妆照"；严肃影视、电影感项目取"电影级古装定妆照"（与 `references/风格美学锚点库.md` 古偶/网感的使用限制一致）。

## 8. 标准输出结构

### 8.1 输出模板

古装填写 `templates/角色设定卡模板.md`（女性模板 A、男性模板 B）；现代填写 `templates/现代角色设定卡模板.md`（女性模板 C、男性模板 D）。模板段落顺序：总述与风格 → 四栏排版 → 去头与对齐 → 身材比例与机位 → 第一栏面部与妆容 → 分栏光照 → 服装 → 发型首饰 → 各栏展示重点 → 背景与质量后缀 → 负面词。各段参数从本文件 §2、§3、§5、§6 取。

### 8.2 技术规格

- 画质提示：4K、电影级画质、真实摄影质感（实际分辨率由生成平台参数决定，写进提示词只起画质暗示作用）
- 渲染重点：眼部反射光、皮肤质感、头发细节、材质微观结构

### 8.3 非古装题材

- **现代题材**（都市、职场、校园、偶像）：直接用 `templates/现代角色设定卡模板.md`，参数从下面的现代参数库取。
- **科幻、奇幻等其他题材**：以模板 C/D 为底，沿用排版、去头、身材比例、分栏光照和背景，只替换妆容、服装、发型、首饰段落；服装同样按"颜色 + 版型 + 材质 + 痕迹"写（材质词见 `references/材质叙事词典.md`）；负面词用 §9 通用块，再追加对应题材的廉价感（如"廉价cosplay作战服、塑料感护甲"）。
- **服装要露出身材**：至少一件贴身或收腰单品，并写明腰头或腰线位置。只穿长袍、长大衣、宽松卫衣时，全身栏看不出头身比；测试中古装宽袖长袍就看不出身高差，换成修身上衣加高腰直筒长裤后才能判断。

## 10. 与角色设计的区分

| 维度 | 角色设计（references/角色设计.md） | 资产标准化（本文件） |
|------|----------------------|-------------------|
| 输出目的 | 概念定调 / 视觉探索 | 锁定角色资产 / 可复用参数 |
| 画面构图 | 自由构图，可融入场景 | 固定四栏排版，浅冷灰背景 |
| 角色姿态 | 可做动作表情 | 统一站立：正面、侧面去头全身 + 背面全身 |
| 风格自由度 | 高 | 低（写实摄影风） |
| 输出用途 | 看"感觉"对不对 | 后续视频/分镜复用 |

**适用判断：** 先做角色概念设计确认方向，再做资产标准化锁定参数。
