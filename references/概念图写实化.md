# 概念图写实化

> 适用：客户提供的美术概念图、CG 渲染图、游戏原画、AI 生成初稿，需要转化为电影/电视剧级写实摄影质感（图生图、图像编辑）
> 核心目标：在不改变构图、主体内容、角色识别特征的前提下，消除 CG 感/塑料感/动画感/过度油光，重建真实光影层次

---

## 0. 核心原则（与其他任务的本质区别）

本任务与角色设计、场景构建、资产标准化的输入逻辑不同：

| 维度 | 角色设计 / 场景构建 / 资产标准化 | 概念图写实化 |
|------|--------------|---------|
| 输入 | 纯文字描述，从零构思 | 客户提供的参考图，图已存在 |
| 任务性质 | 生成（Generation） | 转化（Transformation） |
| 构图/内容 | 由提示词自由定义 | 必须锁定，不可更改 |
| 提示词写法 | 描述式（"画面是什么"） | 编辑式（"保留什么，改变什么"） |

**两条铁律：**

1. **内容锁定，材质转译**——主体、构图、机位、场景/角色的核心识别特征（建筑布局、山海关系、人物五官轮廓、发型服装款式）必须原样保留，只转化渲染方式、材质质感和光照逻辑。
2. **"写实化"不等于"只去油"**——很多情况下，客户原图的时间/光源氛围本身就不适合最终呈现（例如原图是冷调夜景暴风雨，但项目需要的是温暖治愈的日间氛围），这时需要连带光源逻辑一起重做，而不是在原光源基础上小修小补。是否需要重做光源，取决于诊断结果（见 §1），不能一概而论。

必读 `references/写实质感控制.md`；其他资料按诊断结果调用，调用关系见本文件 §7。

---

## 1. 参考图诊断清单（输出提示词前必须先做）

**前提：必须真的看到参考图。** 用户没有上传，或当前环境无法查看图片时，说明情况并请用户上传或用文字描述画面，不能凭空判断 CG 感来源和光源问题。

**在写转化提示词之前，先用 3-5 行文字总结参考图现状。** 这一步不能跳过——诊断不准，后面的转化词就是无的放矢。

### 1.1 诊断维度

| 维度 | 要回答的问题 |
|------|------------|
| CG 感来源 | 是材质过于干净统一？边缘过硬？高光过度规则？还是色彩饱和度堆叠导致的"厚涂感"？ |
| 光源现状 | 主光方向、光比、色温是什么？是否均匀受光（平光）缺乏层次？ |
| 材质现状 | 哪些材质表面反光过强/过于统一？哪些缺乏物理痕迹？ |
| 色彩基调 | 当前色调是否服务于最终呈现效果？还是需要连带光源氛围整体调整（见 §0 铁律 2）？ |
| 构图锁定项 | 哪些内容绝对不能变：建筑布局、地标位置、人物五官骨相、发型服装款式、姿态 |

### 1.2 场景类 CG 感常见来源自查表

| 现象 | 成因 | 对应修复方向 |
|------|------|------------|
| 水面/云层反光过于规则、呈块状高光 | 游戏引擎/渲染器的镜面反射算法痕迹 | 打散反光为不规则漫反射，见 §3.2 |
| 远景轮廓生硬、缺乏空气透视 | 缺少大气介质层 | 补充空气透视层，见 §3.3 |
| 建筑/植被材质过于鲜艳干净 | 贴图渲染没有物理痕迹 | 材质叙事注入环境侵蚀感 |
| 整体色彩饱和度统一堆叠、缺乏明暗过渡 | CG 厚涂式配色 | 降低饱和度统一性，增加自然曝光滚降 |

### 1.3 人物类 CG 感常见来源自查表

| 现象 | 成因 | 对应修复方向 |
|------|------|------------|
| 皮肤蜡感、过于光滑均匀 | 磨皮/渲染引擎的次表面散射简化 | 加毛孔+细纹+肤色变化，见 §4.1 |
| 五官"数字建模感"，过度对称精修 | 3D 建模/AI 生成的默认对称倾向 | 保留骨相个性化差异，避免完美对称描述 |
| 眼神呆滞、直视镜头无交流感 | 渲染引擎默认视线 | 加微表情/视线偏移小词 |
| 发丝过于顺滑，无碎发层次 | 毛发系统简化渲染 | 加自然毛流+碎发+飞发描述 |
| 服装材质发亮如塑料膜 | 材质球反射参数过高 | 织物真实感描述，见 §4.3 |
| 整体光照均匀无层次（平光） | 简化布光或缺乏方向性主光 | 引入方向性主光+阴影层次 |

## 2. 实战案例参考

> 以下为真实项目前后对比案例，作为诊断和转化标准的参照基准。

### 案例 A：大荒学堂海岛场景（场景类）

- **原图现状**：深蓝紫冷调暴风夜海景，云层浓重压迫，海浪汹涌但呈现游戏渲染的"数字感"——浪花过于统一细密，海面反光呈规则塑料高光点，建筑瓦片过于鲜艳干净，整体冷调饱和度统一堆叠，远景山体轮廓生硬缺乏大气透视。
- **诊断结论**：CG 感主要来自反光规则化+缺乏空气透视+材质过于干净；同时原设定的冷调暴风夜氛围本身不适合最终呈现效果。
- **转化动作**：光源从冷蓝暴风夜整体重做为暖金黄昏（触发 §0 铁律 2），云层柔化并补充真实大气透视层，海面改为不规则漫反射+哑光质感，建筑材质做旧降低鲜艳度，整体呈现真实航拍/摄影棚微缩摄影质感。
- **保留项**：整体构图、建筑布局与地标位置（灯塔礁石、桥梁、殿宇群分布）完全不变。

### 案例 B：泰衣人物四栏资产卡（人物类）

- **原图现状**：白灰色薄衣汉服人物四栏卡，皮肤过于光滑均匀如蜡像，五官比例过度对称精修，眼神呆滞直视镜头，头发过于顺滑无碎发层次，服装材质发亮似塑料膜，整体平光无层次。
- **诊断结论**：典型的皮肤蜡感+五官数字建模感+材质塑料化组合问题，光源逻辑（棚拍灰背景四栏）本身不需要重做，只需做材质和皮肤层面的写实化转译。
- **转化动作**：皮肤加毛孔/细纹/自然肤色变化，眼神加自然微笑和视线交流感，发丝加碎发和自然毛流质感，服装材质改为哑光织物+自然褶皱垂坠，光照在原有棚拍逻辑上增加明暗层次（不再是纯平光）。
- **保留项**：四栏构图、人物五官骨相轮廓、服装款式（三层色叠结构）、姿态、灰背景完全不变。

**两个案例的共同规律**：场景类问题往往需要判断是否要重做光源氛围（案例A重做了），人物类问题通常只需材质/皮肤层面转译、光源逻辑保留（案例B未重做光源）。诊断时先判断落在哪一类。

## 3. 场景写实化转换规则

### 3.1 光影氛围重塑

**先判断**：原光源逻辑是否服务于最终效果？

- **保留原光源逻辑**：只做材质质感升级，光源方向/色温不变，参考 `references/风格美学锚点库.md` 中对应风格的"光线设计"小节
- **整体重新设计光源**：从 `references/场景构建.md` §3 光照时空锚点重新选择（黄金时刻/蓝调时刻/阴天漫射/月光夜/室内烛火），明确写出"由 XX 光源改为 XX 光源"

### 3.2 材质去 CG 化词库

| CG 渲染表现 | 写实转化写法 |
|------------|------------|
| 水面/玻璃规则镜面反射 | 不规则漫反射、破碎波光、非统一反射角 |
| 建筑贴图过于鲜艳干净 | 材质叙事注入侵蚀痕迹（见 `references/材质叙事词典.md` 一、二节） |
| 植被色块过于统一 | 明暗层次不均的自然植被色、局部枯黄/湿润差异 |
| 云层/天空过于平滑 | 云层体积感、边缘不规则、局部透光不均 |

### 3.3 空气透视重建

中远景之间补充空气介质层（薄雾/体积雾/湿气/风沙/雪粉/光束/烟尘），具体写法参考 `references/场景构建.md` §1.2。这是消除"贴图背景感"的关键一步，CG 渲染图最常见的问题就是远景缺乏这层介质。

## 4. 人物写实化转换规则

### 4.1 皮肤去蜡感

真实毛孔、细纹、细小汗毛、面中自然薄红、鼻翼/眼下真实肤色变化、非均匀受光。组合公式见 `references/写实质感控制.md` §一。

**核心判断**：原图皮肤问题是"磨皮过度"还是"渲染引擎次表面散射简化"？前者加毛孔细纹即可，后者还需加"皮肤内部通透感、皮下血管隐约透出的自然肤色变化"。

### 4.2 面部"数字建模感"消除

- 避免"五官对称精修"的描述倾向，保留骨相个性化的细微不对称
- 加视线偏移小词：不死盯镜头、自然视线方向、微表情含蓄
- 具体骨相/眼型/眉形参数复用 `references/角色设计.md` §1

### 4.3 服装材质去塑料化

真实织物纤维、细密织纹、自然褶皱、柔软垂坠、袖缘轻微磨砂、暗纹织进布料里。具体见 `references/资产标准化.md` §3.4 织物真实感规则。

### 4.4 发丝真实感

自然毛流、鬓边碎发、发尾分束和细小飞发，不要假发块状感、不要塑料反光。

## 5. 输出结构

严格分两段输出，使用 `templates/写实转化提示词模板.md`：

1. **参考图现状分析**（3-5行，对应 §1 诊断清单）
2. **转化提示词**（编辑式写法：保留项 + 改变项，明确到材质/光源/色调三个层面）

**编辑式写法示例：**
> 保持原图构图、建筑布局、地标位置不变；将画面光源由冷蓝暴风夜调整为暖金黄昏侧光，云层增加真实大气透视与体积感；水面反光由规则镜面高光改为不规则漫反射，哑光质感；建筑材质降低鲜艳饱和度，注入风化侵蚀痕迹；整体去除 CG 厚涂感，呈现真实摄影/航拍质感。

## 6. 常见失败修复表

| 问题 | 修复方法 |
|------|---------|
| 转化后画面变糊/细节丢失 | 检查是否误删了保留项的具体描述，编辑式提示词的"保留项"必须写得和"改变项"一样具体 |
| 转化后角色/建筑认不出来了 | 内容锁定描述不够具体，需明确写出五官骨相/建筑布局的关键坐标特征 |
| 只去油没解决"假"的问题 | 说明问题根源在光源逻辑而非材质，回到 §1 诊断重新判断是否需要重做光源（参考案例A） |
| 场景转化后氛围违和 | 检查是否该保留原光源却重做了，或该重做光源却只做了材质升级——先诊断判断类别（参考案例A/B的差异） |
| 人物转化后五官漂移 | 复用 `references/资产标准化.md` §1.3 的跨视图一致性规则，面部参数写死 |
| 四栏卡转化后全身照小脸出油 | 按 `references/资产标准化.md` §7.1 分栏光照：特写侧逆光，全身柔光 + 面部哑光粉感 |
| 转化后画面变脏 | 颗粒噪点改"轻微"，不写"不要干净无层次"，见 `references/写实质感控制.md` §四 |

## 7. 与其他资料的调用关系

本任务不重复定义材质词库和光照锚点，全部复用：

- 皮肤真实感、去油、光学瑕疵 → `references/写实质感控制.md`
- 材质叙事、环境侵蚀痕迹 → `references/材质叙事词典.md`
- 风格锚点及各风格光线设计 → `references/风格美学锚点库.md`
- 光照时空锚点、空间分层、空气透视 → `references/场景构建.md`
- 人物面部/服装/皮肤参数、分栏光照 → `references/角色设计.md`、`references/资产标准化.md`

**适用判断**：客户明确提供参考图并要求"写实化/去油/更真实/更像真人拍摄/去 AI 感"时使用本流程；如果是从零文字描述生成新角色/场景，走角色设计、场景构建、资产标准化。
